# Sports News Recommendation System!!!!

An end-to-end data science prototype built to mirror sports media personalization and subscription conversion workflows. Raw user click logs from the **Microsoft News Dataset (MIND)** are filtered and transformed into analytics-ready feature tables using **dbt + DuckDB**, then served through a **Dockerized Streamlit** application.

## Features
- **ELT Data Pipeline (`dbt` + `DuckDB`):** Transforms raw tab-delimited news and behavior logs into clean, sports-only feature tables (`sports_news`, `sports_interactions`, `user_features`).
- **Dual Recommendation Engines:** Compare a fast, interpretable **Content-Based (TF-IDF + Cosine Similarity)** baseline against **Collaborative Filtering (Sparse TruncatedSVD)** live in the UI.
- **News-Specific Controls:** Interactive **Recency Decay** slider (exponential decay) to balance breaking news vs. evergreen content, plus a **Cold-Start** fallback for zero-history visitors.
- **Subscription Propensity Scoring:** A Logistic Regression classifier that predicts conversion likelihood and visualizes feature-level log-odds contributions.

## Prerequisites
- **Python 3.11+**
- **Docker** (optional, for containerized deployment)

---

## 1. Clone the Repository

```bash
git clone https://github.com/enboyd94/msnews-recommendations.git
cd msnews-recommendations
```

## 2. Download & Place the MIND-Small Dataset

1. Download the **MIND-small (Training)** dataset from the [Microsoft News Dataset page](https://msnews.github.io/) (or via [Kaggle](https://www.kaggle.com/datasets/arashnic/mind-news-dataset)).
2. Unzip the archive and create a `data/` folder in the repo root:
   ```bash
   mkdir -p data
   ```
3. Move and rename `news.tsv` and `behaviors.tsv` into `data/` so your directory looks like this:
   ```text
   data/
   ├── news_train.tsv
   └── behaviors_train.tsv
   ```
   *(Note: `data/` is gitignored to keep raw logs and the DuckDB binary out of version control.)*

---

## 3. Build the DuckDB Database with dbt

Create a virtual environment, install dependencies, and run the dbt pipeline to materialize the sports tables into `data/mind.duckdb`:

```bash
python -m venv .venv
source .venv/bin/activate        # On Windows: .venv\Scripts\activate
pip install -r requirements.txt

cd dbt_mind
dbt run --profiles-dir .
cd ..
```

Verify that `data/mind.duckdb` was created and that `sports_news`, `sports_interactions`, and `user_features` materialized as **tables**.

---

## 4. Run the Streamlit App

### Option A: Run with Docker (Recommended)
Build the image and mount your local `data/` folder as a read-only volume:

```bash
docker build -t msnews-recsys .
docker run -p 8501:8501 -v "$(pwd)/data:/app/data:ro" msnews-recsys
```
*(On Windows PowerShell, replace `$(pwd)` with `${PWD}`.)*

### Option B: Run Locally
With your virtual environment activated:

```bash
streamlit run app.py
```

Open **`http://localhost:8501`** in your browser.

  ```bash

Note that the local UI for the duckDB and Streamlit use the same port, so stop the Streamlit app before proceeding to the tables. 

## Notes & Limitations
- **Simulated Fields:** The public MIND dataset does not include article publish timestamps or subscription billing labels. `hours_ago`, `avg_read_time_min`, and the binary conversion target are simulated to demonstrate recency decay and propensity modeling end-to-end.
- **Production Scaling:** In a production environment, swapping `dbt-duckdb` for a cloud warehouse adapter (e.g., `dbt-snowflake` or `dbt-bigquery`) requires only updating `profiles.yml`.
